1. Who operates this

This policy covers "youth-housing-shorts", a private desktop script run by one individual creator to upload videos to their own YouTube channel, "연봉 안 보는 청년주택". It is not a company product and is not offered to anyone else.

이 정책은 채널 운영자 한 명이 자기 채널에 영상을 올리기 위해 개인 PC에서 쓰는 스크립트에 적용됩니다.

2. Users

The only user is the channel owner. No viewers, subscribers, or other people sign in to or interact with the script.

사용자는 채널 운영자 본인 1명뿐이며, 다른 사람은 로그인하거나 이용하지 않습니다.

3. What YouTube API data is accessed

  • videos.insert: to upload videos to the owner's channel.
  • channels.list (mine=true): to confirm which channel is authorized.

The script does not read comments, subscribers, viewer data, analytics, or any other user's or channel's data.

본인 채널 업로드와 연결 채널 확인에만 YouTube API를 사용하며, 댓글·구독자·시청자 정보는 읽지 않습니다.

4. What is stored, and where

  • The OAuth refresh token for the owner's own Google account.
  • The IDs of videos the script uploaded.

Both are kept only on the owner's computer. Nothing is stored on a server, and no personal data of any third party is collected.

본인 계정의 인증 토큰과 업로드한 영상 ID만 본인 PC에 저장합니다. 제3자의 개인정보는 수집하지 않습니다.

5. Sharing

No YouTube API data is sold, shared, transferred, or used for advertising or profiling.

YouTube API로 얻은 데이터는 판매·공유·광고 목적으로 쓰지 않습니다.

6. Content sources

Videos summarize public rental housing notices published by the Seoul Metropolitan Government's Youth Safe Housing program (https://soco.seoul.go.kr/youth/main/main.do). These notices are public documents and contain no personal data used by this script.

7. Revoking access and deleting data

You can revoke this API client's access to your Google account at any time through the Google security settings page: https://security.google.com/settings/security/permissions

Stored data (the OAuth token and uploaded video IDs) is deleted from the owner's computer within 7 days after access is revoked, or immediately on request through the contact details below. Uploaded videos themselves can be deleted at any time in YouTube Studio. No YouTube API data is kept for longer than 30 days without being refreshed.

접근 권한은 위 Google 보안 설정 페이지에서 언제든지 철회할 수 있으며, 철회 후 7일 이내 또는 요청 즉시 저장된 토큰과 영상 ID를 삭제합니다.
